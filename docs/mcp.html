mcp.endpointfeed.com

Query EndpointFeed from any MCP client

EndpointFeed's aggregated Intune / SCCM / M365 / endpoint-management feed data is available as a public MCP server, hosted on Cloudflare Workers. No authentication required — the underlying data is already public. Add it once with claude mcp add (or any Streamable HTTP–capable client) and ask for the latest Intune news, search across every tracked source, or check which feeds are currently failing.

claude mcp add --transport http endpointfeed https://mcp.endpointfeed.com

Anything else

Any client that supports MCP's Streamable HTTP transport can connect straight to https://mcp.endpointfeed.com.

Capabilities

Four tools, backed directly by the live feeds.json.
list_feeds

Lists every source EndpointFeed tracks — blogs, YouTube channels, podcasts, official vendor blogs — with each feed's id, label, type, badge, item count, and last-fetch error if any. Call this first to discover valid feed_id / type values for the other tools.

No parameters
search_items

Keyword search across item title, summary, and author, with optional filters. Returns newest matches first.

ParamDescription
queryKeyword to match against title/summary/author
categoryFilter to items tagged with this category
typerss / video / official / audio
feed_idFilter to a single feed
sinceISO 8601 date — only items on/after this
limit1–100, default 20
latest

The most recently published items across all feeds.

ParamDescription
limit1–100, default 10
typerss / video / official / audio
feed_health

Lists feeds whose last scheduled fetch failed, with the error message and timestamp — a quick way to see what's currently broken upstream.

No parameters

How it works

  • Data Reads the live feeds.json published at endpointfeed.com/feeds.json, regenerated every 4 hours by the Fetch RSS Feeds GitHub Action.
  • Caching Fetched through Cloudflare's edge cache (5 min TTL) — results are at most 5 minutes stale, no per-call origin fetch.
  • Stateless A fresh MCP server instance handles every request — no Durable Objects, no stored state, no auth.
  • Source Open in the repo under mcp-server/.
